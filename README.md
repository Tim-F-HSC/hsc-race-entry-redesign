# \# HSC Race Entry Redevelopment

# 

# \## Purpose

# 

# Redevelop the Helensburgh Sailing Club race entry system.

# 

# \## Objectives

# 

# \- Design for mobile phones first, while supporting desktop computers.

# \- Improve the layout, usability and visual appearance.

# \- Review the existing CSV data files and plan a safe migration to JSON where appropriate.

# \- Preserve the essential features of the current system.

# \- Develop and test separately from the live website.

# 

# \## Development approach

# 

# \- Use GitHub to manage source code and track changes.

# \- Test with fictional data during development.

# \- Keep the existing live system operational until the replacement has been tested and approved.
